# Third-party components

UI-Scanner can invoke third-party security tools as backend implementation
adapters. These dependencies retain their own names, licenses, copyright notices,
and distribution requirements.

Current internal adapters:

- Nikto — https://github.com/sullo/nikto
- Nuclei — https://github.com/projectdiscovery/nuclei
- Nmap — https://nmap.org/

This file exists for engineering/licensing transparency. Customer-facing scan
results use SkullHarbor's normalized finding model and do not expose implementation
details unless disclosure is required by license, contract, support, or law.
